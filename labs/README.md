# Labs

One file per hands-on exercise, numbered by module. **Every lab is
individual work** on the learner's own laptop and free ChatGPT. Every source
text is **fabricated for training and unclassified**, labeled that way on the
page, and one page or less, since there are no file uploads. Each lab ends
with an instructor section (answer key and pitfalls). Remove that section
before printing participant copies.

**The take-home thread** runs through Labs 04 and 05. Each learner builds a
template for their own recurring task, then tests and refines it.
