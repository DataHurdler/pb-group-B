## If something goes wrong

| Problem | Do this |
| --- | --- |
| Running 10+ minutes late | Cut the current lab's stretch task. Then Lab 03 Part C, then Lab 05 Part C. Shorten the capstone to 25 minutes. Never cut the knowledge check or the close |
| A participant can't reach the tool | Pair them with a neighbor for labs. For the capstone, use a spare seat or schedule a supervised make-up |
| The tool is down for everyone | Run the labs on paper: pairs write prompts, and the instructor runs the best ones once the tool is back, or shows pre-captured outputs from the dry run |
| Someone pastes real work data | Stop them, gently and at once. Follow the command's spill or incident procedure if it's sensitive. Remind the room of the data rule without naming the person |
| A question on AI policy you can't answer | "That's for `[AI / cybersecurity office POC]`." Write it down and include the answer in the follow-up |
