# Module 06 — Capstone

Status: draft
Time: 3:00–3:30 (30 min, individual, assessed) · Objective(s): all

Each participant takes a raw, fabricated packet (an email thread plus a small
data table) and produces a one-page decision memo for a director, using their
own prompts on the approved tool. It's the whole day in one task: data rule,
six slots, executive structure, a template, and checking.

- **Task and packet:** [labs/06-capstone-decision-memo.md](../../labs/06-capstone-decision-memo.md)
- **Scoring:** [assessment/capstone-rubric.md](../../assessment/capstone-rubric.md)
- **Participants submit:** (1) every prompt they used, (2) the final memo,
  (3) their verification notes, and (4) one reusable template.

| Min | Activity |
| --- | --- |
| 0–2 | Hand out the packet; read the task aloud; start the clock |
| 2–25 | Individual work. No help on content; help with tool access only |
| 25–30 | Submit (email to the instructor, or paste into the submission form). Participants check their own memo against the rubric while they wait |

## Instructor notes

- **Individual means individual.** Pairs split for this block. It's the only
  time all day that participants work alone.
- **If running late,** shorten to 25 minutes and say so at the start. Don't
  extend into the close.
- **Score after the course**, within 2 business days. The certificate goes out
  with the follow-up email ([assessment/follow-up.md](../../assessment/follow-up.md)).
