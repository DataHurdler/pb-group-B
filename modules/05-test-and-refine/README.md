# Module 05 — Test and Refine

**Objective:** LO4. Refine prompts through iterative testing and evaluation. (Also serves LO3: accuracy.)

**Time:** 60 minutes, 2:15–3:15 (15 teaching, 45 activity)

## What it teaches

1. **How output goes wrong:** changed numbers, invented facts, invented authorities, and lost caveats. Polished output makes errors more convincing.
2. **Write criteria before you test.** Three to five checks someone else could apply, written *before* you run anything, so "better" means something.
3. **Change one thing at a time.** If you change three things and it improves, you don't know which one worked.
4. **Know when not to use AI:** anything the tool can't hold, decisions about people, final legal or policy interpretations, and anything you can't check.

## How it's taught

1. **Hook (3 min):** a polished AI summary on screen. *"Would you send this to the Chief of Staff?"* Hands up. Then: *"It has four errors."*
2. **The four failure types, and the defences (6 min):** "use only the text provided," "quote the source line for each claim," check numbers by hand, and ask a fresh chat to critique it.
3. **Criteria, then one change at a time (4 min):** show a bad criterion ("it's good") beside a good one ("the deadline is in the first sentence").
4. **When not to use AI (2 min):** the list above. Wider responsible-use questions belong in *AI Ethics and Governance*.

## Activity

1. **10 min, individuals:** [Lab 05 Part A](../../labs/05-test-and-refine.md). Find the four errors by hand, with no AI.
2. **7 min, individuals:** Part B. Make the AI show its work, and compare its check with yours.
3. **20 min, individuals:** Part C. **Test and refine your own template:** write 3 criteria, run it, score it, change one thing, run it again, and score again. Then a cold test in a new chat.
4. **8 min, whole room:** *Who found all four errors? Which was hardest?* Then one volunteer reads their criteria and the one change that helped most.

## Materials

- Lab 05 sheet, a pen, and each learner's template from Module 04

## Notes for the instructor

- **The errors are planted on purpose.** The answer key is in the lab. Don't reveal the count until the hook.
- **Common stumble:** criteria nobody else could check ("clear," "professional"). Ask: *"Could a colleague score that without asking you?"*
- **Most learners miss the invented authority** ("Per DoD policy…"). Spend the debrief there. It's the most dangerous error for this audience.

## If time runs short

Cut Part B. **Never cut Part C.** It turns the template into a *tested* template, which is what the charter promises.
