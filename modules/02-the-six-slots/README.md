# Module 02 — The Six Slots

**Objective:** LO2. Write clear, structured prompts that produce more useful and relevant outputs.

**Time:** 60 minutes, 10:00–11:00 (15 teaching, 45 activity)

## What it teaches

1. **A prompt has six slots:** Task, Context, Audience, Format, Constraints, Example. Weak output usually means one is empty.
2. **Paste the source, and say "use only this."** It's the strongest guard against invented facts.
3. **Ask it to ask you.** *"Before you write, ask me any questions you need answered."* It shows which slot you left empty.

## How it's taught

1. **Hook (3 min):** a vague prompt and its generic output on screen. *"What did it have to guess?"*
2. **The six slots (12 min):** each slot with the failure you get when it's empty, then one prompt rebuilt slot by slot on screen. Hand out the [six-slots card](../../handouts/six-slots-card.md).

| Slot | The question it answers | Failure when empty |
| --- | --- | --- |
| **Task** | What exactly do you want produced? | It does something adjacent |
| **Context** | What does it need to know that it can't? | Generic, made-up details |
| **Audience** | Who will read it, and what do they care about? | Wrong tone and depth |
| **Format** | Length, structure, headings, bullets? | A wall of text, or the wrong product |
| **Constraints** | What must it not do? | Invented facts, banned phrasing |
| **Example** | What does good look like? | A style you then have to fix |

## Activity

1. **35 min, individuals:** [Lab 02: Rebuild a vague prompt](../../labs/02-rebuild-a-vague-prompt.md). Add one slot at a time, v0 to v5, each in a new chat.
2. **10 min, whole room:** two volunteers read their v0 and v5 aloud, and the instructor runs v5 on the projector. *Which slot made the biggest jump?*

## Materials

- Lab 02 sheet, six-slots card, slides

## Notes for the instructor

- **Name the failure before the fix.** Show the generic output first, then the slot that fixes it.
- **Skip "act as a world-class expert" folklore.** A role line helps a little. Context and audience help a lot.
- **Common stumble:** adding to one chat instead of starting a new one per version. Then the comparison isn't fair.

## If time runs short

Cut the Lab 02 stretch task and step 4 ("ask it to ask you"). Never cut v0 vs v1: it's the grounding lesson.

Call a 2-minute stretch at 11:00, before Module 03.
