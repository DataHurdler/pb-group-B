# Module 07 — Close: Your 30-Day Plan

Status: draft
Time: 3:45–4:00 (15 min) · Objective(s): LO4

Making AI part of daily work happens in the next 30 days or not at all. The
close turns the day into a commitment each person writes down.

| Min | Activity |
| --- | --- |
| 0–3 | Back to the board from the welcome: the recurring tasks the room named. Which ones now have a template? |
| 3–10 | Each person writes their **30-day plan** on a card: <br>1. Two recurring tasks I'll use AI for, and when I'll first do it <br>2. The template I'll save and reuse <br>3. One task I've decided *not* to use AI for, and why <br>Read one line aloud, round the room |
| 10–15 | Exit ticket ([feedback/exit-ticket.md](../../feedback/exit-ticket.md)). Explain how and when certificates of completion arrive. Remind them where the prompt library is |

Never cut this block. If the day runs late, take the minutes from Module 06.

**After the course:** the follow-up email asks, at 30 days, which part of the
plan happened. That answer is the best measure of whether the course worked.
